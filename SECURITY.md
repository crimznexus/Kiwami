# Security Policy

Only the [latest release](https://github.com/crimznexus/Kiwami/releases/latest) receives fixes.

To report a vulnerability, please do not open a public issue. Use GitHub's private reporting:
https://github.com/crimznexus/Kiwami/security/advisories/new

Include what you found, how to reproduce it, and the Kiwami version. You can expect a first reply within a few days.

Note that third-party extensions are not part of Kiwami and run with the app's permissions. Report problems in an extension to its own repository.
